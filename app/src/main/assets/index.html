Bine ai venit în Umbra

Un set de instrumente pentru investigații „paranormale”, create pentru distracție.

  • Vedere termică — un efect de culoare peste imaginea camerei. Simulare, nu măsurătoare.
  • Detector EMF — citește câmpul magnetic real al telefonului. Nu detectează fantome.
  • Cutia spiritelor — cuvinte alese la întâmplare.
  • Jurnal — sesiuni, note și capturi, salvate doar pe telefonul tău.

Camera este folosită doar după permisiunea ta, iar imaginea nu părăsește telefonul.
